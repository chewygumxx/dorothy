# Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dorothy's persona and memory in Codex, through `dorothy
--codex`, and in Hermes Agent, through a memory provider in a `dorothy`
profile, both served by one host hook command.

**Architecture:** `@dorothy/memory` gains `"./host-hook"`: payload
parsing per host and `runHostHook`, which asks her service for the block
or recall and answers in Codex's hook shape, failing open. `@dorothy/cli`
gains `--hook`, `--codex` (session flags only, no file written) and
`--install hermes`, which drives `hermes profile create` and writes her
`SOUL.md`, her provider plugin and four configuration keys. The
provider, Python with the standard library alone, runs `--hook`.

**Tech Stack:** Bun and TypeScript; `node:util` `parseArgs`; Bun's
`Bun.TOML.parse`; `yaml` 2.9.1; Python 3.11+ standard library
(`subprocess`, `json`, `unittest`).

**Spec:** [`docs/specs/2026-11-01-delivery-design.md`](../specs/2026-11-01-delivery-design.md)

## Global Constraints

- New subsystems stay independent of any model provider's SDK, speaking
  standard protocols, with SDK types at a thin edge.
- Tests and probes never touch real user data (`$XDG_DATA_HOME/dorothy`,
  `$XDG_CACHE_HOME/dorothy`): every root, key and environment is passed
  in. Probes run hosts on temporary homes (`CODEX_HOME`, `HERMES_HOME`).
- Launchers write none of a host's files; only `--install`, run by the
  user, writes, and only the files and keys it owns.
- Never pass `--dangerously-bypass-hook-trust` to Codex.
- Probes never copy a host's login (`auth.json`): the user signs each
  temporary host home in, and trusts its hooks, themselves.
- Live probes run Dorothy on temporary `XDG_*` roots with a probe
  service of her own (`DOROTHY_MEMORY_URL`), never the user's store or
  service.
- Hosts run Dorothy through `selfCommand` (`bun --no-env-file <entry>`);
  an install writes the main checkout's entry, never a worktree's.
- The persona is `identityPrompt()` from `@dorothy/identity`, the same
  text byte for byte in every host.
- Hooks and the provider fail open: an empty reply, exit 0, never an
  error in the user's session.
- Every new file carries the house header, copied from a sibling;
  `bun run lint:header` syncs headers.
- `packages/cli/AGENTS.md` and `packages/memory/AGENTS.md` are at their
  150-line budget, the root `AGENTS.md` at 100: detail goes in nested
  guides, and a line added means a line saved nearby.
- Conventional Commits, scopes the package names; headers at most 50
  characters, body lines at most 72; no em dash; no trailers.

## Review Focus

- A Codex payload missing `cwd` or `session_id`, or a `source` Codex adds
  later: the hook answers nothing and exits 0, rather than throwing.
- A user whose Codex `config.toml` sets `developer_instructions` already:
  their text follows hers in the flag, quoted, never dropped.
- An install run twice, or after the user edited the profile's
  `config.yaml`: only her four keys change, the user's other keys stay.
- The service down and not startable: the hook returns `""` within its
  timeouts and the provider an empty block, never a Python traceback.
- An install run from a worktree: it writes the main checkout's entry,
  and refuses if no main checkout is found.

## Departures from the spec

Ruled before execution, each with its cost if wrong:

1. `HOOK_HOSTS` is a list in `args.ts`, pinned by a test to the
   profiles whose `delivery` lists `hook` or `plugin`, not read from
   them at run time, so `--help` loads no profile. Cost: a new host is
   two edits.
2. `userInstructions` reads the user's and the project's
   `.codex/config.toml`, the project's winning, as Codex merges them;
   a `--profile`'s instructions are not read. Cost: a profile's
   `developer_instructions` is replaced in her sessions.
3. `runHostHook` logs a failure to her hook log
   (`bodies/log.ts`, `claude-hook.log`), the log her hooks share.
   Cost: one log for every host's hooks.
4. `--install hermes --entry <path>` names the entry to write, for
   probes from a branch; without it, the main checkout's. The install
   checks its entry answers `--hook`. Cost: one flag more.

```ts
// A host hook's payload, Codex's or her Hermes provider's, read into
// what a block or recall request needs. Anything unreadable is null: a
// hook answers nothing then, rather than failing the host's turn.

import { BLOCK_REASONS, type BlockReason } from "@dorothy/core";

export const HOOK_EVENTS = ["session-start", "prompt"] as const;
export type HookEvent = (typeof HOOK_EVENTS)[number];

export type HookInput = {
    session: string;
    cwd: string;
    reason: BlockReason;
    prompt: string | null;
};

const text = (value: unknown): string | null =>
    typeof value === "string" && value.trim() !== "" ? value : null;

// A source the contract does not name, such as a fork, opens as a start.
const reasonOf = (source: unknown): BlockReason =>
    BLOCK_REASONS.find((reason) => reason === source) ?? "startup";

export function parseHookInput(
    event: HookEvent,
    json: unknown,
): HookInput | null {
    if (typeof json !== "object" || json === null) {
        return null;
    }
    const payload = json as Record<string, unknown>;
    const session = text(payload.session_id);
    const cwd = text(payload.cwd);
    if (session === null || cwd === null) {
        return null;
    }
    if (event === "session-start") {
        return { session, cwd, reason: reasonOf(payload.source), prompt: null };
    }
    const prompt = text(payload.prompt);
    return prompt === null
        ? null
        : { session, cwd, reason: "startup", prompt };
}
```

- [ ] **Step 7: Write `run.ts`**

```ts
// dorothy --hook <host> <event>: a host's hook, Codex's or her Hermes
// provider's, answered from her service. The block for a session's
// start, recall for a prompt, each as Codex's hook output; "" whenever
// there is nothing to say or the service cannot say it.

import { type HookLog, hookLog } from "../bodies/log.js";
import { identify as identifyProject } from "../projects/identify.js";
import {
    type ClientOptions,
    ensureService,
    requestBlock,
    requestRecall,
} from "../service/client.js";
import { type HookEvent, parseHookInput } from "./payload.js";

export type HostHookDeps = {
    client?: ClientOptions;
    // How to start the service when it is down; [] starts none.
    serve?: readonly string[];
    identify?: (cwd: string) => Promise<{ id: string } | null>;
    // Her hook log by default, where her Claude Code hooks write too.
    log?: HookLog;
};

const EVENT_NAMES: Record<HookEvent, string> = {
    "session-start": "SessionStart",
    prompt: "UserPromptSubmit",
};

const reply = (event: HookEvent, text: string): string =>
    text === ""
        ? ""
        : JSON.stringify({
              hookSpecificOutput: {
                  hookEventName: EVENT_NAMES[event],
                  additionalContext: text,
              },
          });

export async function runHostHook(
    host: string,
    event: HookEvent,
    stdin: string,
    deps: HostHookDeps = {},
): Promise<string> {
    let json: unknown;
    try {
        json = JSON.parse(stdin);
    } catch {
        return "";
    }
    const input = parseHookInput(event, json);
    if (input === null) {
        return "";
    }
    const client = deps.client ?? {};
    const log = deps.log ?? hookLog(client.env ?? process.env);
    const failed = (what: string) =>
        log.warn(`${host} ${event}: ${what}; answered nothing`);
    try {
        await ensureService(deps.serve ?? [], client);
        const found = await (deps.identify ?? identifyProject)(input.cwd).catch(
            () => null,
        );
        const project = found?.id;
        const scope = project === undefined ? {} : { project };
        if (event === "session-start") {
            const block = await requestBlock(
                { host, session: input.session, reason: input.reason, ...scope },
                client,
            );
            if (block === null) {
                failed("no block from the service");
            }
            return reply(event, block?.text ?? "");
        }
        const recall = await requestRecall(
            {
                host,
                session: input.session,
                prompt: input.prompt ?? "",
                ...scope,
            },
            client,
        );
        if (recall === null) {
            failed("no recall from the service");
        }
        return reply(event, recall?.text ?? "");
    } catch (error) {
        failed(error instanceof Error ? error.message : String(error));
        return "";
    }
}
```

```ts
// The entry script as it sits in the repository's main checkout, for
// what outlives a session: a worktree may be removed, its path with it.
// null outside a repository.
export function mainEntry(
    entry: string,
    git: (args: string[], cwd: string) => string | null = runGit,
): string | null {
    const dir = dirname(entry);
    const top = git(["rev-parse", "--show-toplevel"], dir);
    const common = git(
        ["rev-parse", "--path-format=absolute", "--git-common-dir"],
        dir,
    );
    if (top === null || common === null) {
        return null;
    }
    return join(dirname(common), relative(top, entry));
}

function runGit(args: string[], cwd: string): string | null {
    const result = Bun.spawnSync(["git", ...args], { cwd, stderr: "ignore" });
    const out = result.stdout.toString().trim();
    return result.exitCode === 0 && out !== "" ? out : null;
}
```

```ts
// as session flags before the user's own. Nothing of Codex's is written;
// Codex asks the user, once, to trust her hooks, and keeps that itself.

import { mkdir, readFile, writeFile } from "node:fs/promises";
import { homedir } from "node:os";
import { dirname, join } from "node:path";
import type { Env } from "@dorothy/core";
import { identityPrompt } from "@dorothy/identity";
import { type Spawned, selfCommand, shellWord, spawnInherited } from "../self.js";

const CODEX = "codex";
const SERVER = "dorothy";

// A TOML basic string: JSON's escapes are TOML's for these characters.
const toml = (text: string) => JSON.stringify(text);
const tomlArray = (words: readonly string[]) =>
    `[${words.map(toml).join(",")}]`;

const hook = (self: readonly string[], event: string) =>
    `[{hooks=[{type="command",command=${toml(
        [...self, "--hook", "codex", event].map(shellWord).join(" "),
    )}}]}]`;

export function codexArgs(options: {
    self: readonly string[];
    persona: string;
    theirs: string | null;
}): string[] {
    const { self, persona, theirs } = options;
    const instructions =
        theirs === null ? persona : `${persona}\n\n${theirs}`;
    const set = [
        `developer_instructions=${toml(instructions)}`,
        `mcp_servers.${SERVER}.command=${toml(self[0] ?? "")}`,
        `mcp_servers.${SERVER}.args=${tomlArray([
            ...self.slice(1),
            "--mcp",
            "--host",
            "codex",
        ])}`,
        `hooks.SessionStart=${hook(self, "session-start")}`,
        `hooks.UserPromptSubmit=${hook(self, "prompt")}`,
        "memories.use_memories=false",
        "memories.generate_memories=false",
    ];
    return ["--enable", "hooks", ...set.flatMap((flag) => ["-c", flag])];
}

// The user's own developer_instructions, which a session flag would
// otherwise replace: the last config holding one, as Codex lets the
// project's override the user's; null for none, or for a file that
// does not parse.
export function userInstructions(
    ...configs: (string | null)[]
): string | null {
    let found: string | null = null;
    for (const config of configs) {
        if (config === null) {
            continue;
        }
        try {
            const value = (Bun.TOML.parse(config) as Record<string, unknown>)
                .developer_instructions;
            if (typeof value === "string" && value !== "") {
                found = value;
            }
        } catch {}
    }
    return found;
}

export type CodexDeps = {
    env?: Env;
    cwd?: string;
    which?: (command: string, options: { PATH: string }) => string | null;
    // The user's config.toml and the project's, either null.

    // `codex --version`'s version, or null.
    version?: (codex: string) => string | null;
    spawn?: (cmd: string[], env: Env) => Spawned;
    write?: (text: string) => void;
    self?: readonly string[];
    persona?: string;
};

const codexHome = (env: Env) =>
    env.CODEX_HOME || join(env.HOME || homedir(), ".codex");

const readText = (path: string) => readFile(path, "utf8").catch(() => null);

const readCodexConfigs = async (env: Env, cwd: string) => [
    await readText(join(codexHome(env), "config.toml")),
    await readText(join(cwd, ".codex", "config.toml")),
];

const codexVersion = (codex: string): string | null => {
    const run = Bun.spawnSync([codex, "--version"], { stderr: "ignore" });
    return run.stdout.toString().match(/\d+\.\d+\.\d+/)?.[0] ?? null;
};

const stateDir = (env: Env) =>
    join(env.XDG_STATE_HOME || join(env.HOME || homedir(), ".local/state"), "dorothy");

export async function codexCommand(
    args: readonly string[],
    deps: CodexDeps = {},
): Promise<string[] | null> {
    const {
        env = process.env,
        cwd = process.cwd(),
        which = Bun.which,
        readConfigs = readCodexConfigs,
        write = (text) => process.stderr.write(text),
        self = selfCommand(),
        persona = identityPrompt(),
    } = deps;
    const codex = which(CODEX, { PATH: env.PATH ?? "" });
    if (codex === null) {
        write("dorothy: codex is not on PATH\n");
        return null;
    }
    const theirs = userInstructions(...(await readConfigs(env, cwd)));
    return [codex, ...codexArgs({ self, persona, theirs }), ...args];
}

// Codex asks the user to trust a hook whose command it has not seen:
// said before the first session, and again when her command changes.
async function noteTrust(
    env: Env,
    self: readonly string[],
    write: (text: string) => void,
): Promise<void> {
    const path = join(stateDir(env), "codex-hooks.digest");
    const digest = Bun.hash(self.join("\0")).toString(16);
    if ((await readText(path))?.trim() === digest) {
        return;
    }
    write(
        "dorothy: Codex will ask you to trust her two hooks; trust them for her memory.\n",
    );
    await mkdir(dirname(path), { recursive: true, mode: 0o700 });
    await writeFile(path, `${digest}\n`);
}

export async function runCodex(
    args: readonly string[],
    deps: CodexDeps = {},
): Promise<number> {
    const {
        env = process.env,
        spawn = spawnInherited,
        version = codexVersion,
        write = (text) => process.stderr.write(text),
        self = selfCommand(),
    } = deps;
    const command = await codexCommand(args, deps);
    if (command === null) {
        return 1;
    }
    const { loadProfiles } = await import("@dorothy/memory/host-hook");
    const checked = (await loadProfiles()).get("codex")?.checked ?? [];
    const running = version(command[0] ?? "");
    if (running !== null && !checked.includes(running)) {

        );
    }
    await noteTrust(env, self, write);
    return spawn(command, env).exited;
}
```

```python
"""Dorothy's memory for Hermes Agent: her opening block, frozen for the
session, and recall for each prompt, both from `dorothy --hook hermes`,
which finds the project, caches the block and fails open itself. Her
tools come from her MCP server; her sweep records the sessions."""

import json
import os
import subprocess

from agent.memory_provider import MemoryProvider

CONFIG = "dorothy.json"
# Inside the 8 seconds Hermes gives an external provider's prefetch.
TIMEOUT = 6.0

def _home():
    return os.environ.get("HERMES_HOME") or os.path.expanduser("~/.hermes")

def _configured_command():
    try:
        with open(os.path.join(_home(), CONFIG)) as f:
            command = json.load(f).get("command")
    except (OSError, ValueError):
        return None
    if isinstance(command, list) and all(isinstance(w, str) for w in command):
        return command
    return None

class DorothyProvider(MemoryProvider):
    def __init__(self, command=None, cwd=None, timeout=TIMEOUT):
        self._command = command
        self._cwd = cwd
        self._timeout = timeout
        self._session = ""
        self._block = None

    @property
    def name(self):
        return "dorothy"

    def is_available(self):
        return self._command is not None

    def unavailable_reason(self):
        return "run `dorothy --install hermes` to set her provider up"

    def initialize(self, session_id, **kwargs):
        self._session = session_id or ""
        self._cwd = self._cwd or kwargs.get("cwd") or os.getcwd()

    def _hook(self, event, payload):
        if self._command is None:
            return ""
        try:
            done = subprocess.run(
                [*self._command, "--hook", "hermes", event],
                input=json.dumps(payload),
                capture_output=True,
                text=True,
                timeout=self._timeout,
            )
            if done.returncode != 0 or done.stdout.strip() == "":
                return ""
            text = json.loads(done.stdout)["hookSpecificOutput"]["additionalContext"]
            return text if isinstance(text, str) else ""
        except (OSError, ValueError, KeyError, TypeError, subprocess.TimeoutExpired):
            return ""

    def system_prompt_block(self):
        if self._block is None:
            self._block = self._hook(
                "session-start",
                {"session_id": self._session, "cwd": self._cwd, "source": "startup"},
            )
        return self._block

    def prefetch(self, query, *, session_id=""):
        return self._hook(
            "prompt",
            {"session_id": session_id or self._session, "cwd": self._cwd, "prompt": query},
        )

    def queue_prefetch(self, query, *, session_id=""):
        # Hermes calls this once a turn is over, with that turn's text.
        return None

    def sync_turn(self, *args, **kwargs):
        # Her sweep records Hermes's sessions.
        return None

    def get_tool_schemas(self):
        return []

    def handle_tool_call(self, tool_name, args, **kwargs):
        return json.dumps({"error": f"dorothy has no tool {tool_name}"})

    def shutdown(self):
        return None

def register(ctx):
    ctx.register_memory_provider(DorothyProvider(command=_configured_command()))
```

```ts
// dorothy --install hermes: a Hermes profile of hers, beside the user's.
// Hermes makes it from the user's own (--clone, no alias); she then owns
// its SOUL.md, her plugin, dorothy.json and four configuration keys,
// and nothing else in it or in any other profile.

import { cp, mkdir, readFile, writeFile } from "node:fs/promises";
import { join } from "node:path";
import { parseDocument } from "yaml";

const PROFILE = "dorothy";
const PLUGIN = join(import.meta.dir, "../../assets/hermes/dorothy");

export type HermesDeps = {
    home: string;
    run: (cmd: string[]) => Promise<number>;
    self: string[];
    persona: string;
    force?: boolean;
    write: (text: string) => void;
};

const profileDir = (home: string) => join(home, "profiles", PROFILE);
const read = (path: string) => readFile(path, "utf8").catch(() => null);

const digest = (text: string) => Bun.hash(text).toString(16);

type Marker = { command: string[]; soul: string };

const readMarker = async (dir: string): Promise<Marker | null> => {
    const text = await read(join(dir, "dorothy.json"));
    try {
        return text === null ? null : (JSON.parse(text) as Marker);
    } catch {
        return null;
    }
};

// Whether her command answers --hook: an entry from before --hook was
// built exits 2, and the provider would answer nothing, unseen.
const answersHook = async (self: string[]) =>
    (await Bun.spawn([...self, "--hook", "hermes", "prompt"], {
        stdin: new Blob(["{}"]),
        stdout: "ignore",
        stderr: "ignore",
    }).exited) === 0;

export async function installHermes(deps: HermesDeps): Promise<number> {
    if (!(await (deps.answers ?? answersHook)(deps.self))) {
        deps.write(`dorothy: ${deps.self.join(" ")} does not answer --hook\n`);
        return 1;
    }
    const dir = profileDir(deps.home);
    const config = join(dir, "config.yaml");
    const marker = await readMarker(dir);
    let made = false;
    if ((await read(config)) === null) {
        const code = await deps.run([
            "hermes", "profile", "create", PROFILE, "--no-alias", "--clone",
        ]);
        if (code !== 0) {
            deps.write("dorothy: hermes could not make her profile\n");
            return 1;
        }
        made = true;
    } else if (marker === null && !deps.force) {
        deps.write(`dorothy: ${dir} is not a profile she made; --force takes it\n`);
        return 1;
    }
    const soul = join(dir, "SOUL.md");
    const persona = `${deps.persona}\n`;
    const present = await read(soul);
    // Hers when this run made the profile (its SOUL.md the clone's), or
    // when it is still what she last wrote.
    const hers =
        made || present === null || present === persona ||
        (marker !== null && digest(present) === marker.soul);
    if (!hers && !deps.force) {
        deps.write(`dorothy: ${soul} was edited since she wrote it; --force replaces it\n`);
        return 1;
    }
    await writeFile(soul, persona);
    await mkdir(join(dir, "plugins"), { recursive: true });
    await cp(PLUGIN, join(dir, "plugins", PROFILE), {
        recursive: true,
        filter: (path) => !path.includes("__pycache__"),
    });
    await writeFile(
        join(dir, "dorothy.json"),
        `${JSON.stringify({ command: deps.self, soul: digest(persona) }, null, 4)}\n`,
    );
    // Her keys alone, merged into a document whose comments and other
    // keys stay as the user left them.
    const document = parseDocument((await read(config)) ?? "{}\n");
    document.setIn(["memory", "provider"], PROFILE);
    document.setIn(["memory", "memory_enabled"], false);
    document.setIn(["memory", "user_profile_enabled"], false);
    document.setIn(["mcp_servers", PROFILE], {
        command: deps.self[0],
        args: [...deps.self.slice(1), "--mcp", "--host", "hermes"],
    });
    await writeFile(config, document.toString());
    for (const file of ["SOUL.md", "plugins/dorothy/", "dorothy.json", "config.yaml"]) {
        deps.write(`dorothy: wrote ${join(dir, file)}\n`);
    }
    deps.write("dorothy: start her with `hermes -p dorothy`\n");
    return 0;
}

export async function uninstallHermes(deps: HermesDeps): Promise<number> {
    if ((await readMarker(profileDir(deps.home))) === null) {
        deps.write("dorothy: no profile of hers to remove\n");
        return 1;
    }
    return deps.run(["hermes", "profile", "delete", PROFILE, "--yes"]);
}
```

```ts
const INSTALL_USAGE =
    "--install takes hermes [--uninstall] [--force] [--entry <path>]";

function parseInstall(rest: readonly string[]): Mode {
    const [host, ...flags] = rest;
    const parsed = options(flags, {
        uninstall: { type: "boolean" },
        force: { type: "boolean" },
        entry: { type: "string" },
    });
    if (host !== "hermes" || parsed === null || parsed.positionals.length > 0) {

    return {
        kind: "install",
        host,
        uninstall: parsed.values.uninstall === true,
        force: parsed.values.force === true,
        entry: parsed.values.entry ?? null,
    };
}
```

```ts
                            readHermesSession(path, row.id, previous, options),
                    })),
                );
            }
            return found;
        },
```

`readdir` joins the `node:fs/promises` import; `SourceSession` is the
element type `Source["list"]` returns, under whatever name `sources.ts`
gives it. A session's key is unchanged for the default profile, so
nothing swept before is swept again.
