# slugify

`slugify(text)` in `src/slug.ts` turns a title into a URL slug:

- The slug is lower case.
- A letter with a diacritic becomes its plain letter: `Crème` is
  `creme`. Other non-ASCII characters count as separators.
- Each run of characters that are not ASCII letters or digits becomes
  one hyphen.
- The slug never starts or ends with a hyphen.
- Text with no letters or digits gives the empty string.

Examples, which `bun src/example.ts` runs:

```text
"Hello, World!"      -> "hello-world"
"  spaced   out  "   -> "spaced-out"
```

The owner holds a fuller test than the examples and runs it on the exact
revision you submit. Do not edit this file or anything outside your
clone.
