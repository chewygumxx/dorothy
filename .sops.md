# .sops.md

`.sops.yaml` tells sops to encrypt `secrets.json` to one age recipient:

- `age1c2u90auft2qgu5cyf358pqq2jk89s847lhy465836tjqycvnwpasj6td9w`

Its private half lives in `~/.config/sops/age/keys.txt`, off the
repository. `pairs.test.ts` fails if the recipients named here, the ones
in `.sops.yaml` and the ones `secrets.json` was encrypted to differ.

core's `saveSecret` reads `.sops.yaml` beside the file it writes, so the
rule must stay next to `secrets.json`.
