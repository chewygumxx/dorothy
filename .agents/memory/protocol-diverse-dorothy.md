Ruled 2026-10-18: Dorothy is protocol diverse. No one harness hosts her,
Hermes Agent and OpenClaw included; one definition of her (identity,
voice, skills, MCP servers) is generated into each harness's own files
(SOUL.md, agent files, system prompt flags), optionally with a proxy that
puts her persona into any harness's requests, and one memory serves them
all. That ruling excluded Pi. Memory across harnesses is designed before
choosing harnesses, and existing packages (langchain-ai's, tools as
adopted as rulesync) are researched before anything bespoke.

**Why:** the user rejected the inherited framing of Hermes against
OpenClaw as hosts, and a single body
([minutes](../../docs/reports/2026-10-18-protocol-diversity.md)).

On 2026-11-03 the user explicitly made Pi the highest priority, following
the [Pi research](../../docs/notes/2026-11-03_pi-stewardship.md). This
supersedes the exclusion of Pi. Their chief interest is stewardship and
orchestration of Claude Code and Codex through herdr. Choosing Pi first
does not itself decide whether Dorothy's existing runtime is replaced.

**How to apply:** prioritise Pi integration and its stewardship trial;
do not repeat the old exclusion as current guidance. Keep identity and
memory portable while the integration's design is settled, and survey
adopted packages before building.
Memory follows [memory priorities](./memory-priorities.md).
